MISE EN LIGNE FACILE AVEC GITHUB PAGES (gratuit)
1. Sur un ordinateur, crée un compte sur https://github.com si tu n'en as pas.
2. Crée un nouveau dépôt public nommé caisse-barbier-iphone.
3. Choisis "Add file" > "Upload files", puis téléverse TOUS les fichiers du dossier (pas le dossier lui-même).
4. Clique "Commit changes".
5. Dans le dépôt, ouvre Settings > Pages.
6. Dans "Build and deployment", choisis "Deploy from a branch", branche "main", dossier "/ (root)", puis Save.
7. Attends quelques minutes. L'adresse sera du type https://TON-PSEUDO.github.io/caisse-barbier-iphone/
   (remplace TON-PSEUDO par ton identifiant GitHub).

INSTALLER SUR IPHONE
1. Ouvre l'adresse publiée dans Safari sur l'iPhone.
2. Appuie sur le bouton Partager.
3. Choisis "Sur l'écran d'accueil" / "Ajouter à l'écran d'accueil".
4. Confirme. L'icône "Ma Caisse Barbier" apparaît sur l'écran d'accueil.

IMPORTANT — DONNÉES ET SAUVEGARDE
- Les prestations sont enregistrées dans le stockage local du navigateur de l'appareil. Elles ne sont PAS automatiquement synchronisées avec un autre téléphone ou ordinateur.
- Utilise régulièrement "Exporter la sauvegarde" et conserve le fichier JSON dans Fichiers/iCloud Drive ou sur ton ordinateur.
- Pour restaurer, ouvre l'application sur le nouvel appareil et choisis "Importer une sauvegarde".
- Évite de vider l'historique Safari / les données du site sans avoir exporté une sauvegarde.
- La version GitHub Pages est publique pour toute personne ayant l'adresse, mais les données de caisse restent localement dans le navigateur et ne sont pas envoyées à GitHub.
- Cette application est un outil de suivi interne, pas un logiciel de caisse certifié ni une comptabilité complète.
- Teste l'application avec quelques entrées avant de t'y fier pour tes recettes réelles.
